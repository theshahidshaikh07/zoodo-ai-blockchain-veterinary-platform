# Agent Rules & Guidelines

## Browser Tool Policy
- **STRICT PROHIBITION**: NEVER launch or use `browser_subagent` or any browser automation tools.
- Do NOT open browser windows, navigate URLs, click, or take browser screenshots.
- All testing and validation must be conducted exclusively via code inspection, file viewing, and non-browser terminal commands (such as `npx tsc --noEmit`, test suites, or linters).
